## ① 후보 220개 만들기 (`build_candidates`)

### 어떤 큐브를 미나

| 종류 | 개수 | 규칙 |
|---|---|---|
| 이웃 밀기 | 180 | 대상에서 **가까운 이웃 6개** (`cand_neighbours`), 그중 120mm 안의 이웃만 유효 × 이웃의 양쪽 옆 2 × 방향 5 × 거리 3 |
| 대상 밀기 | 12 | 대상 자체를 **네 면 방향** × 거리 3 (`cand_target`) |
| 벽 관련 | 28 | 대상이 벽에 가까울 때만 유효 (벽 쪽 틈이 18 + 2mm 미만). 벽 4개 × (벽 맞추기 1 + 벽 따라 양쪽 2 × 거리 3). **벽 맞추기는 꺼 둠** (`cand_wall_square = False`) |

슬롯 순서는 고정: 가까운 이웃부터, 같은 이웃이면 긴 거리부터. 동점일 때 앞 슬롯이 우선된다.

### 어느 방향으로

이웃 밀기는 "대상 → 이웃" 방향을 기준으로 **0°, 22.5°, 45°, 67.5°, 90°** (`cand_angles`)

- 0° = 이웃을 대상 옆에서 **옆으로 비켜나게**
- 90° = 이웃을 대상에서 **곧장 멀어지게**
- 대상 쪽으로 미는 방향은 없다

### 몇 mm

- 큐브가 밀리는 거리 **35 / 25 / 15mm** (`cand_dists`). 손가락은 여기에 5mm(시작 간격) 더 움직인다
- 민 큐브가 벽 **3mm 앞**에 오면 멈춤 (`wall_push_gap`). 줄인 거리로 3mm도 못 밀면 그 후보는 제외

### 어디서 시작하나

밀 큐브 **반대쪽**, 큐브 면에서 **5mm** 떨어진 바닥 (`start_clearance`)

### 결과 예측 (기하)

- 큐브가 **회전 없이 민 거리만큼** 그대로 움직인다고 가정
- 그 자리에서 다른 큐브나 벽과 겹치면 **줄줄이 밀림**(`chain`) 표시. 실제 물리는 이 예측과 다를 수 있다 (예측 정확도 약 74%)

## ② 위험한 후보 빼기 (`landing_free`)

아래를 모두 만족해야 **안전**(`valid`). 안전한 후보가 하나도 없으면 실패 −5 (시작점 막힘).

| 검사 | 규칙 |
|---|---|
| 착지 자리 | 닫힌 손가락이 바닥에 닿는 자리 (14 × 15.4mm, `finger_foot_half`) **+ 사방 2mm 여유** (`safety_margin`)에 큐브가 없어야 함 |
| 벽 안쪽 | 시작점과 끝점에서 손가락 자리가 트레이 벽 안에 들어가야 함 |
| 하우징·카메라 | 밀 때 하우징·카메라 아래 면이 벽 높이(30mm)보다 낮으면 벽에 안 닿아야 함. 지금은 둘 다 벽보다 높아 검사에 걸리지 않음 |
| 이웃 범위 | 이웃 밀기는 대상에서 120mm 안의 이웃만 (`obs_neighbour_radius`) |

## ③ 후보마다 정보 계산 (`observe`)

정책 입력 = 대상 주변 정보 **51개** + 후보마다 **12개 × 220** = **2,691개**. 카메라로 본 위치(오차 포함)로 계산한다.

### 대상 주변 정보 (51개)

| 값 | 개수 | 규칙 |
|---|---|---|
| 대상 각도 | 2 | sin(4θ), cos(4θ). 정사각형이라 90°마다 같은 모양 |
| 벽까지 거리 | 4 | 대상 중심에서 대상 기준 네 방향으로 벽까지 (0.1m 단위, 최대 2) |
| 손가락 자리 비었나 | 4 | 대상 네 면 바깥 18 × 20mm가 비었나 (1/0) |
| 가까운 이웃 8개 | 40 | 이웃마다 상대 위치(x, y), 상대 각도 sin/cos(4Δθ), 있음 여부. **120mm 밖은 "없음"**. 거리순 (같으면 번호순) |
| 민 횟수 | 1 | 지금까지 민 횟수 ÷ 최대 밀기(3) |

### 후보마다 정보 (12개)

| 번호 | 값 | 규칙 |
|---|---|---|
| 0~1 | 시작점 위치 | 대상 기준 좌표 ÷ 0.1m |
| 2~3 | 미는 방향 | 대상 각도 대비 sin, cos |
| 4 | 거리 | 손가락 이동 거리 ÷ 0.04m |
| 5~6 | 밀 큐브 위치 | 대상 기준 좌표 ÷ 0.1m |
| 7 | **열림 예측** | 예측한 배치에서 대상 한 축의 양쪽이 18 × 20mm씩 비나 (`grasp_axes_clear`) |
| 8 | **줄줄이 밀림** | 민 큐브가 다른 큐브나 벽과 겹치나 |
| 9 | 안전 | ②의 결과 |
| 10 | **모자란 틈** | 예측한 배치에서 열리려면 틈이 얼마나 더 필요한가 (`open_deficit`). 두 축 중 나은 쪽, 양쪽 면 부족분의 합 ÷ 18mm (0 = 열림) |
| 11 | **다음 수에 열림** | 모자란 틈이 **가장 작은 6개**만 한 수 더 계산 (`lookahead_info`, `lookahead_topk`). 그 배치에서 다음 밀기로 열리는 안전한 후보가 생기면 1, 나머지 후보는 0 |

- 안전하지 않은 후보는 12개 값을 모두 0으로 만든다
- **11번의 6개를 고를 때 동점이면 앞 슬롯 우선** (안정 정렬). 예전 `topk`는 동점을 CPU와 GPU에서 다르게 골라 실물(CPU)에서만 입력이 달라지는 문제가 있었다 (11/26 수정, 시뮬 결과는 그대로)

## ④ 220개 중 1개 고르기: 강화학습 (`CandidatePolicy`)

| 항목 | 내용 |
|---|---|
| 점수 | 후보마다 [대상 주변 51 + 그 후보 12 = 63개] → 신경망 (128-128, ELU) → 점수 1개. **220개에 같은 신경망을 적용** |
| 막기 | 안전하지 않은 후보는 점수 −∞ (선택 불가) |
| 학습 중 | 점수를 softmax로 확률로 바꿔 **확률대로 뽑음** (탐색) |
| 실행·평가 | **점수가 가장 높은 후보** |
| 학습 방식 | categorical PPO (학습률 3e-4, 엔트로피 0.01, gamma 0.9, lambda 0.95, clip 0.2) |
| 배운 기준 | 사람이 정하지 않음. 아래 보상을 최대로 하도록 시뮬에서 실제 물리 결과로 배움 |

### 보상 (`fr5_push_env.py:290` `_get_rewards`)

| 항목 | 점수 |
|---|---|
| 성공 (실제로 집어 들어 올림) | +10 |
| 밀기 1번 | −1 |
| 손가락 이동 거리 | 1cm당 −0.1 |
| 실패 | −5 |
| 틈 보상 | 모자란 틈이 1mm 줄 때마다 +0.17 (늘면 감점, 실패한 판은 없음) |

### 비교용 탐색 규칙 (`push_geom.py:324` `demo_push_action`)

④를 사람이 정한 규칙으로 채운 것. 강화학습의 비교 기준(같은 배치에서 85.9%)이다.

- 바로 열리는 후보가 있으면: 열림 예측 **+2**, 열림 예측이고 줄줄이 밀림 없음 **+0.5**, 앞 슬롯 조금 우선(−0.001 × 슬롯 번호)
- 없으면: 다음 수에 열림 **+4**, 모자란 틈 **1mm당 −0.1**

## ⑤ 밀기 실행 (`_pre_physics_step`, `_apply_action`)

| 단계 | 시간 | 규칙 |
|---|---|---|
| 준비 | — | 그리퍼 각도 = **미는 방향 + 90°** (닫힌 손가락의 평평한 면으로 밂). 손가락은 닫힌 위치에 **고정** (`lock_fingers_push`) |
| 내려가기 | 0.4초 | 시작점 위 손끝 35mm(`safe_tip_z`) → **17mm**(`push_tip_z`) |
| 착지 확인 | 내려가기 + 0.1초 | 손끝이 목표보다 **3mm 넘게** 높으면 "큐브 위 착지" → 실패 −5 |
| 밀기 | 1.6초 | 손끝 17mm 유지, **25mm/s**(`push_speed`)로 정해진 거리만큼 |
| 물러나기 | 0.15초 | 미는 반대 방향으로 **5mm**(`push_backoff`). 들 때 큐브를 끌어올리지 않게 |
| 들기·대기 | 나머지 | 손끝 35mm로 올라간 뒤 큐브가 멈출 때까지 대기. 밀기 1번 = 2.8초 |

## ⑥ 실패 확인 → 열림 판정 → 집기 (`_get_dones`, `grasp_attempt`)

### 1. 실패 확인 (하나라도 있으면 −5로 끝)

| 실패 | 기준 |
|---|---|
| 넘어짐 | 대상이 **15°** 넘게 기울어짐 (`tilt_fail_deg`) |
| 쌓임 | 아무 큐브든 중심이 **16.5mm**보다 높음 (`stacked_z`, 정상 12.5mm) |
| 큐브 위 착지 | ⑤에서 확인 |
| 시작점 막힘 | ②에서 안전한 후보가 하나도 없었음 (`fail_on_blocked`) |
| 모서리 | 대상이 모서리에 낌(x 벽·y 벽 쪽 틈 모두 18mm 미만, `target_in_corner`) → 그 뒤 **2번 더** 밀어도 못 듦 (`corner_fail_after`) |

### 2. 열림 판정 (`grasp_axes_clear`)

- 카메라로 본 위치(위치 ±3mm, 각도 ±5° 균등 오차)로 판정
- 대상의 **한 축 양쪽 면 바깥이 깊이 18mm × 폭 20mm씩 비어** 있으면 열림 (`finger_clear_depth`, `finger_clear_width`)
- 0° 축이 먼저, 안 되면 90° 축

### 3. 집기 (열림일 때)

| 순서 | 규칙 |
|---|---|
| 1 | 손가락 벌림 **30.8mm** (70%, 손가락마다 15.4mm) |
| 2 | 손끝 **12mm**까지 내려감 |
| 3 | 닫기 (시뮬 손가락 힘 5N) |
| 4 | 손가락이 **12.3~13.2mm** (56~60%)에서 멈췄으면 쥔 것 |
| 5 | **60mm** 들기 → 큐브가 원래보다 **30mm 넘게** 올라가 있으면 **성공 +10** |

### 4. 다음

- 성공 또는 실패 → 판 끝
- 둘 다 아니고 밀기를 **3번** 다 썼으면 → 끝 (시간 초과, 벌점 없음. 실물에서는 사람 호출)
- 아직 남았으면 → ①로 돌아가 다시 봄
