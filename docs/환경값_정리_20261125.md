# fr5_push 밀기 강화학습 환경값 정리 (2026-11-25)

Isaac Lab 밀기 학습 환경(`fr5_push`)의 현재 설정 전체. 값의 출처는
`source/fr5_push/fr5_push/tasks/direct/fr5_push/fr5_push_env_cfg.py`, 실물 값은
`choco_ws/src/fr5_task/config/points.yaml`.

- **이 환경이 하는 일**: 집을 큐브(대상)의 두 잡기 축이 모두 막혔을 때, 밀어서 한 축을 연다. 강화학습은 "어느 후보로 밀지"만 고른다.
- **행동 방식 (11/25 03시부터)**: 실행할 후보 = argmax(탐색 규칙 점수 + 정책 점수). 정책은 규칙을 보정하는 역할. 이유는 [`변경내역_20261125.md`](변경내역_20261125.md) 9번.
- **학습하지 않는 것**: 열림 판정, 집기, 들기, 놓기 (모두 규칙). 대상이 처음부터 열려 있으면 실물에서는 밀지 않고 바로 집는다.
- **"대상(빨강)"**: 색 red가 아니라 "지금 집을 큐브" 표시. 나머지(노랑)는 주변 큐브.

## 1. 환경

| 항목 | 값 | 비고 |
|---|---|---|
| 트레이 | 안쪽 300 × 300mm, 벽 높이 30mm, 벽 두께 8mm, 직각 모서리 | 안쪽 치수 실측 확인 필요 |
| 큐브 | 25mm, **19개** (글자 16 + 숫자 3), 15g, 마찰 정지 0.6 / 운동 0.5 | 무게·마찰은 추정 |
| 로봇 | 팔 없이 떠 있는 PGEA 그리퍼 (가상 관절 px, py, pz, yaw) | FR5 팔·IK 없음 |
| TCP | 플랜지에서 160mm (손가락 끝) | 실물 `TCP: [0,0,160]` |
| 큐브 배치 | 트레이 전체에 무작위로 흩뿌린 뒤 두 축이 다 막힌 큐브를 대상으로 고름. 없으면 이웃을 대상 옆 45mm 안으로 최대 8번 옮겨 붙임 | 20%는 벽 때문에만 막힌 경우도 허용 |
| 큐브 사이 최소 간격 (생성 시) | 0.5mm | |
| **모서리 금지 구역** (11/26) | 큐브 중심이 x 벽·y 벽 모두에서 40mm 안이면 두지 않음 (`corner_free`) | 벽 하나를 따라서는 둘 수 있음 |
| 물리 | dt 1/120초 | |

## 2. 밀기 동작

| 항목 | 값 | 비고 |
|---|---|---|
| 최대 밀기 | **3번** (넘으면 사람 호출) | 설계서·상태머신은 2번. 결정 필요 |
| 큐브가 밀리는 거리 | **15 / 25 / 35mm** | 손가락 이동 거리 = 이 값 + 5mm |
| 내려가는 위치 | 밀 큐브 면에서 **5mm** 떨어진 빈 바닥 | 밀 큐브 반대쪽 |
| 안전 여유 (착지 자리·하우징 검사) | **2mm** | |
| 이동 높이 | 손끝 35mm | |
| 미는 높이 | 손끝 **17mm** (바닥 윗면 기준) | 실물 `PUSH_Z` 바닥 위 17mm |
| 미는 속도 | 25mm/s | |
| 그리퍼 방향 | 미는 방향 + 90° (닫힌 손가락의 평평한 면으로 밂) | |
| 밀 때 손가락 | **닫힘 위치에 고정** | |
| 밀고 난 뒤 | 5mm 뒤로 물러난 뒤 들기 | 들 때 큐브 끌어올림 방지 |
| 벽 앞 멈춤 | 민 큐브가 벽 3mm 앞에 오면 멈춤 | 큐브를 3mm도 못 밀면 후보에서 뺌 |
| 시간표 (밀기 1회 = 2.8초) | 내려가기 0.4 / 밀기 1.6 / 들기 0.4 / 대기 0.4 | |

### 후보 (정책의 행동 = 220개 중 하나 선택)

| 종류 | 개수 | 내용 |
|---|---|---|
| 이웃 밀기 | 180 | 가까운 이웃 6개 × 양옆 2 × 방향 5 × 거리 3 |
| 대상 밀기 | 12 | 대상 네 면 방향 × 거리 3 |
| 벽 관련 | 28 | 벽 4개 × (벽 맞추기 1 + 벽 따라 양쪽 2 × 거리 3). 벽 맞추기는 꺼 둠 |

- 이웃 미는 방향: 0°(옆으로 비키기), 22.5°, 45°, 67.5°, 90°(대상 반대쪽으로 곧게)
- 착지 자리·하우징이 큐브나 벽에 닿는 후보는 미리 뺌 (안전하지 않은 후보는 선택 불가)

## 3. 잡기 판정 / 잡기 동작

| 항목 | 값 | 실물 (`points.yaml`) |
|---|---|---|
| 필요한 틈 깊이 | 큐브 면에서 바깥으로 **18mm** (벽 쪽도 같음) | `GAP_MIN: 18.0` |
| 필요한 틈 폭 | **20mm** | `FINGER_WIDTH: 20.0` (가정) |
| 열림 조건 | 한 축(0° 또는 90°)의 **양쪽 면이 모두** 위 조건 만족 | 같음 |
| 집기 전 벌림 | **70% = 30.8mm** (손가락마다 15.4mm) | `GRIP_OPEN_PCT: 70` |
| 잡을 때 손끝 높이 | **12mm** | `Z_TIP_ABOVE_FLOOR: 12.0` |
| 쥐었는지 판정 | 손가락마다 12.3~13.2mm (약 56~60%) | `GRIP_OK_RANGE: [55, 60]` |
| 잡기 순서 | 벌림 → 손끝 12mm까지 내려감 → 닫기 → 60mm 들기 | |
| 손가락 힘 (시뮬 전용) | 잡을 때 강성 200, 최대 5N | 세게 하면 시뮬에서 손가락이 큐브를 뚫음 |

18mm의 근거: 손가락 안쪽 면이 큐브 면에서 2.9mm(15.4 − 12.5) + 손가락 두께 최대 약 11mm + 여유 약 4mm.

## 4. 성공 / 실패

| 항목 | 값 | 보상 |
|---|---|---|
| **성공** | 실제로 쥐었고 + 큐브가 원래 높이보다 30mm 넘게 들림 | +10 |
| 실패: 넘어짐 | 대상이 15° 넘게 기울어짐 | −5 |
| 실패: 쌓임 | 아무 큐브든 중심이 16.5mm보다 높음 (정상 12.5mm) | −5 |
| 실패: 큐브 위 착지 | 내려간 손끝이 목표보다 3mm 넘게 높음 | −5 |
| 실패: **시작점 막힘** | 안전한 후보가 하나도 없음 | −5 |
| 실패: **모서리** (11/26) | 밀다가 대상이 모서리에 낌(x·y 벽 쪽 틈 모두 18mm 미만) → 그 뒤 2번 더 밀어도 못 듦 (`corner_fail_after`) | −5 |

실패가 생기면 그 판을 바로 끝낸다. 잡기에 실패해도 밀기 횟수가 남으면 다시 보고 계속 민다.

## 8. 기준선 결과 (규칙, 학습 없음)

조건: 이 문서의 설정 그대로 (11/25 01시 측정). 환경 512개, 규칙마다 약 2,500~3,900판, 오차 약 ±1.3%p.

실제로 들어 올린 비율 (누적):

| 방식 | 1번 안에 | 2번 안에 | 3번 안에 | 실패 | 시작점 막힘 |
|---|---|---|---|---|---|
| 규칙 | 65.7% | 82.2% | 86.4% | 0.3% | 0.0% |
| 탐색 규칙 | 64.9% | 82.9% | **87.5%** | 0.4% | 0.0% |
| 무작위 | 24.7% | 40.4% | 52.2% | 0.4% | 0.0% |

한 축 18mm 열림 비율 (누적, 참값):

| 방식 | 1번 안에 | 2번 안에 | 3번 안에 |
|---|---|---|---|
| 규칙 | 70.6% | 79.0% | 80.4% |
| 탐색 규칙 | 71.3% | 80.4% | 81.6% |
| 무작위 | 15.0% | 24.6% | 31.8% |

- 큐브 위 착지 0%, 시작점 막힘 0% (내려가는 위치 5mm + 여유 2mm에서도 안전한 후보가 없는 경우는 없었음).
- 18mm가 안 열렸어도 실제로는 집힌 경우가 있어서 "들어 올림"이 "18mm 열림"보다 높다. 즉 18mm는 넉넉한 기준.
- 2번 → 3번: 탐색 규칙 82.9% → 87.5%, 약 4.6%p 증가 (오차보다 큼).
- 강화학습은 탐색 규칙(87.5%)보다 높아야 실물에 쓸 가치가 있다.

참고, 변경 전 설정(미는 거리 손가락 기준 30/40mm, 내려가는 위치 8mm, 여유 4mm, 시작점 막힘 벌점 없음, 손가락 PD) 탐색 규칙: 1번 64.0% / 2번 80.3% / 3번 85.7%.

## 9. 아직 정해지지 않은 것 / 확인 필요
