### 숫자 읽는 법
- **성공률** = 전체 판 중 밀기 3번 안에 대상을 실제로 들어 올린 비율 (진짜 목표)

### 고르는 방법 (세 가지 모두 같은 후보 중에서 고름)
1. **규칙**: 후보마다 "밀면 바로 열릴까" 예측 -> 열리는 것 (줄줄이 밀림 없는 것, 가까운 이웃 우선). 없으면 첫 번째 후보
2. **탐색 규칙**: 1 과 같고, 바로 열리는 후보가 없으면 "열리기까지 모자란 빈 깊이"를 가장 줄이는 후보 6개를 골라
   "그다음 한 번 더 밀면 열리는 후보가 생기나"를 미리 계산 -> 생기는 것 우선, 없으면 모자란 깊이를 가장 줄이는 것
3. **RL (강화학습)**: 신경망이 후보마다 점수를 매겨 최고점을 실행. 시뮬레이션 512개에서 직접 밀어 보고 받은 보상
   (들어 올림 +10, 밀기 -1, 1cm 당 -0.1, 실패 -5) 으로 스스로 학습 (PPO, 150 이터레이션 ≈ 38만 번 밀기)

RL 설정: 관측 51 + 후보 x 12 (후보 특징 10 + 탐색 정보 2; 지금 148개 -> 1827), 행동 = 후보 수 (후보 점수 -> 안전한 후보 중 최고점 실행),
보상 성공 +10 / 밀기 -1 / 1cm 당 -0.1 / 실패 -5, PPO 환경 512개·환경당 8스텝·256-128-64·lr 1e-4·entropy 0.001·gamma 0.9.

| 열림 판정 후 실제 잡기 | 97~98% |
| "열림 예측" 밀기의 실제 정확도 | 노이즈 없음 82%, 노이즈 있음 63% |
| 기하 예측 상한 (3번) | 84% |
| RL (후보 방식, 벽 80mm 때) | 규칙과 비슷 (59.0% vs 59.5%), 넘지 못함 |

## 남은 문제

1. **벽 옆에 비스듬히 놓인 대상** (현재 실패 약 8%): 벽 맞추기 밀기는 물리에서 실패 -> 밀기만으로는 해결 못함.
   실물에서는 3번 후 사람 호출 / 다른 대상 먼저. 실제 쏟은 배치에서 얼마나 자주 생기는지 확인 필요 (시뮬은 일부러 20% 섞음)
1-1. **노이즈로 잘못 "열림" 판정 후 잡기 시도 (약 15%)**: 실물에서 손가락이 이웃에 닿는지 측정 필요
2. **큐브 쌓임 약 3%**: 거의 전부 "들기" 단계. 미는 높이를 낮추면 크게 늘어남 (17 -> 12.5mm 에서 2.6 -> 11%).
   원인 미확정 -> 화면으로 확인, 조금 높게(20mm) 미는 시험 후보
3. **예측 오차**: "열림 예측" 밀기의 실제 정확도 67.7% (노이즈 없을 때는 더 높음) -> 실제 D435 오차 측정, 여러 장 평균
4. ~~계획 상한 86.1%~~ -> 방향 5종으로 89.3%. RL 에 "두 수 앞" 정보를 줘도 규칙 수준 (위 RL 이력)
5. 실측 필요: **쟁반 바닥 평평한 부분 크기, 테두리 높이·기울기**, D435 장착 위치, 하우징 깊이(Y, 40mm 가정),
   손가락 폭(Y, 20mm 가정), 큐브 재질
6. 실제로 쏟은 배치 사진: 모서리·테두리에 큐브가 얼마나 자주 붙는지에 따라 실제 성공률이 크게 달라짐
